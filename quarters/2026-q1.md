# 2026 Q1

## Goal

Reach [M1 Foundation](../milestones/m1-foundation.md): a system that boots on
real hardware.

## Shipped

Nothing yet. This quarter establishes the base system.

## In progress

| Area | Work | State |
| --- | --- | --- |
| Kernel | Configuration, patches, boot on UEFI and BIOS | In progress |
| Initramfs | `mkinitcpio` profiles for each layout | In progress |
| Boot | GRUB, systemd-boot, EFI stub | In progress |
| System | Core units, sysctl, journald | Planned |
| Filesystem | Layout, permissions, `fstab` | Planned |
| Base | Default configuration | Planned |

## Not started

Everything in waves 4 to 8 of the sequencing plan: packaging beyond the base
set, the ISO, the desktop, the Qinux utilities.

## Decisions this quarter

- The package format is pacman's. Settled in an accepted RFC.
- The base set installs from a local repository, not from an external mirror.
  There is nothing to mirror yet.

## Deliberately not doing

- No desktop environment. It cannot be validated before the ISO exists.
- No graphical installer.
- No custom icon or font work. Visual assets inherit from upstream.

## Carry-over risk

Kernel boot support is the single item that can invalidate the quarter. If it
slips, everything else shifts with it, because nothing can be tested on real
hardware until it works.
