# Proposals

Suggested roadmap changes that have not yet been agreed.

A proposal here is not a commitment. It is a written argument for something,
waiting for a decision.

## Format

One file per proposal, named `YYYY-MM-DD-short-title.md`:

```markdown
# Proposal: something

**Author:** @user
**Date:** 2026-01-05
**Affects:** M3

## Proposal

What should change.

## Motivation

Why this is worth doing.

## Cost

What it costs, honestly.

## Alternatives considered

What else could be done instead.
```

## Process

1. Open the proposal file in a pull request.
2. Discuss it at the next community call.
3. On agreement, it becomes a milestone and moves out of this directory.
4. On rejection, the file stays with a note recording why, so the reasoning is
   not lost.
